## 一、先搞懂线路：四条路，四个价

国内用户访问海外机器，慢和卡基本都出在“回程走哪条路”上。业内常提的四条线，用路来打比方最好理解：

**AS4837（联通普通）**是省道。便宜、车道不算窄，白天跑得挺顺，晚高峰该排队还是排队。它的优点是价格——本文表格里最便宜的那档美国机走的就是它。

**AS9929（联通精品）**是同方向的高速公路。车道更多、路面更好，晚高峰不至于堵死，价格通常只比 4837 贵一点点。圈内把它叫“性价比之王”不是没道理：日常体感和顶级线路差不了太多，账单差得可不少。

**CN2 GIA（电信高端，AS4809）**是机场贵宾通道。电信自建的精品网，三网回程都能借上力，延迟和稳定性第一梯队，价格也第一梯队。它解决的是“晚高峰极限场景”，不是“平时打开快不快”。

**CMIN2（移动精品）**是移动自己的快速路，移动宽带用户访问它延迟最低。香港线路里还常见 CMI，逻辑类似。

一句话对应：**电信用户优先看 CN2 GIA，联通用户优先看 9929，移动用户优先看 CMIN2**；预算紧就退一档选 9929 或 4837，日常使用体感差距没那么大。丽萨主机这批年付特价里没有单独标 CN2 GIA 的型号，线路标签写的是 9929、4837、CMI 和三网直连——想上 GIA 得单独问客服，别默认表里最贵的那档就是 GIA。

还有一条分野容易被忽略：**优化线路 vs 纯国际 BGP**。前者国内快、价格贵；后者国内绕路，但本土解锁能力强、带宽给得大、价格便宜。丽萨主机的新加坡机型就是后者，官方在产品页上写得很直白：“非中国大陆直连优化网络，建议通过香港或日本线路中转使用，香港延迟 30ms，日本延迟 70ms。”这句话不是免责声明，是使用说明——它卖的是 IP 和带宽，不是国内访问速度。

## 二、原生 IP、住宅 IP、双 ISP，三件不同的事

搜 VPS 的人越来越多地问“原生 IP”，但很多人把三个概念混成一个。

**机房 IP**是默认款。整段 IP 属于机房，大量用户共用，TikTok、Instagram、Netflix、亚马逊这些平台早就建了库，新开的机器可能一上手就在灰名单里。

**原生 IP**指的是这个 IP 的注册归属地和机器实际所在地一致，不是从别处广播过来的。它解决的是“地址看着假”的问题，但不等于平台就认你是真人。

**住宅 IP**来自 ISP 的宽带段，平台风控看到的是“某个家庭在上网”，而不是“某台服务器在上网”。做账号运营、跨境电商、需要过验证的场景，这一层才是关键。

**双 ISP**是指这段 IP 在两个运营商都有登记记录，在 IP 检测工具里呈现出的属性更接近真实家宽，也更难被判为机房段。

能不能过风控，最终得自己拿 IP 去查，别信任何人的截图——同一家不同 IP 段的表现都能差出一截。丽萨主机在售的机型里，原生 IP 和双 ISP 住宅 IP 是分开标价的两类产品，价格差得很清楚，下面表格里能直接看到这个差价。

## 五、这几个坑，先说在前面

**48 小时退款是真的，但窗口很短。** 丽萨主机在套餐页统一标注“48 小时不满意，无条件退款”，部分机型还提供按天试用。48 小时足够你测路由、测 IP、装环境，不够你“用一个月再看看”。收到机器第一件事就是跑一遍路由和 IP 检测，别拖到第 4 天。

**优惠码和退款的关系，下单前问清楚。** 行业里普遍的做法是使用优惠码的订单一律不退，丽萨主机的套餐页只写了 48 小时无条件退款，没有单独说明优惠码订单是否适用。稳妥的顺序是：先用月付或按天试用验证 IP 和线路，确认没问题再上年付 + 优惠码。年付省下的钱，不值得用来赌退款。

**新加坡、台湾这类机型不是给国内访客用的。** 新加坡是 BGP 国际网络，官方直接建议用香港或日本中转；台湾线路的回程是电信 163、联通 4837、移动 CMI 这类普通线路，也不是大陆优化。拿它们当国内站的主机，你会得出“这家很慢”的错误结论——它们本来就不干这个活。

**带宽是标称值，不是独享。** 这类价位的机器带宽默认共享，官方通常只保证绝大部分时间段能达到标称峰值。真需要独享带宽，得单独谈，别拿 300Mbps 的宣传数字去规划业务峰值。

**IP 归属地不等于机房位置。** 香港、日本、新加坡这些地方常用广播 IP，查归属地可能显示为别的地区。反过来，原生 IP 的意义就是“查出来跟所在地一致”，这也是它贵的原因。

**别拿它跑违规业务。** 发包、攻击、网盘这类用途在任何一家都是直接封，没有例外。

## 七、常见问题

**月付还是年付？**
第一次买，月付或者按天试用。跑两三个晚高峰、测一遍 IP，觉得稳了再转年付。年付的折扣是给“已经确定要用一年”的人准备的，不是给“想省点钱试试看”的人准备的。

**9929 和 CN2 GIA 差距大吗，值不值加钱？**
日常体感差距不大，都是精品线路，真正的差距出现在晚高峰极限场景和带宽上限上。业务重要、预算够就上 GIA；预算敏感选 9929 一点不丢人。丽萨主机这批年付特价里以 9929、4837、CMI 为主，想要 GIA 型号得单独确认。

**能装 Windows 吗？**
可以，官方在新加坡机型页面上明确写了支持安装 Windows。但 1 核 1G 跑 Windows 是自找麻烦，至少 2 核 2G 起步，4G 内存更稳。

**香港和日本怎么选？**
